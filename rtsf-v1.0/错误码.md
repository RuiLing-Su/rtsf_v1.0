# 错误码

服务拒绝时读取 data.error_code；任务 FAILED 时读取运行错误码。error_msg/detail 仅供说明，不作为程序判断依据。

| 错误码 | 位置 | 含义 | 处理 |
|---|---|---|---|
| SCHEMA_INVALID | 服务回复 | 格式、结构、路由或大小不合法 | 修正报文后提交新请求 |
| VERSION_UNSUPPORTED | 服务回复 | 协议版本不支持 | 核对 schema_version |
| METHOD_UNSUPPORTED | 服务回复 | method 格式合法但不支持 | 核对服务清单 |
| MESSAGE_ID_CONFLICT | 服务回复 | 同一消息 ID 对应不同内容 | 新操作使用新 message_id |
| EXPIRED | 服务回复 | 已达到路径有效期 | 重新确认任务和有效期 |
| MAP_MISMATCH | 服务回复 | 任务与当前地图不一致 | 获取有效地图并重新选点 |
| WAYPOINT_OUT_OF_MAP | 服务回复 | 越界、占用、未知或外形与不可通行区域重叠 | 调整航点，不只检查 bounds |
| ACTION_UNSUPPORTED | 服务回复 | 不支持到点动作 | 移除 action |
| FEATURE_UNSUPPORTED | 服务回复 | 不支持指定航点功能 | 使用支持的航点参数 |
| TASK_NOT_FOUND | 服务回复 | 任务不存在 | 核对任务 ID 和路径受理结果 |
| INVALID_TRANSITION | 服务回复 | 当前状态或未完成操作不允许该调用 | 等待状态更新后判断 |
| STALE_PATH_VERSION | 服务回复 | 路径版本过低 | 核对当前版本 |
| PATH_VERSION_CONFLICT | 服务回复 | 同版本路径内容不同 | 修改内容时递增路径版本 |
| ROBOT_BUSY | 服务回复 | 已有其他非终态任务 | 等待结束或按流程取消 |
| ROBOT_NOT_READY | 服务回复、故障事件 | 设备、定位、时钟、控制或缓存未就绪 | 检查设备端原因 |
| LOCALIZATION_LOST | 服务回复、任务失败、故障事件 | 定位不可用 | 恢复定位并检查现场 |
| PATH_BLOCKED | 任务失败、故障事件 | 无法继续导航或重规划 | 检查障碍与导航结果 |
| LOW_BATTERY | 任务失败、故障事件 | 电量不满足运行条件 | 补充电量 |
| EMERGENCY_STOP | 任务失败、故障事件 | 触发急停 | 检查并解除急停原因 |
| INTERNAL_ERROR | 服务回复、任务失败、故障事件 | 内部异常或进程重启恢复失败 | 保留日志并排查设备端 |

无法可靠提取关联字段的非法输入不保证业务回复。FAILED 和故障通知不替代停稳确认；故障解除不自动恢复终态任务。
